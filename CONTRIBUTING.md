# Contributing

Contributions are welcome!

Please open an issue before starting work on anything beyond a small fix, and read the
[contributing guide](https://docs.goposta.dev/docs/development/contributing) for the development
setup, pull request requirements and conventions. Report security issues privately, as described in
[SECURITY.md](./SECURITY.md).

commercial licensing questions, contact the maintainers.
